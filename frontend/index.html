Free file sharing and text sharing with no account. Share code, markdown, notes, and multi-file uploads with custom URLs and optional password encryption in your browser, send big files browser to browser with Clip Beam, and write together in a real-time live pad.

Live Pad Clip Beam (P2P Transfer) About & Features

Core Features

  • Zero Account Required: Paste text or drag and drop files to generate an instant shareable link. No signup, email, or credentials needed.
  • Optional Client-Side Encryption: Add a password and your text and files are encrypted in your browser with AES-GCM 256-bit before upload.
  • Clip Beam (Peer-to-Peer Transfer): Send large files directly from one browser to another over an encrypted WebRTC connection. Nothing is uploaded, and it resumes if the connection drops.
  • Live Pad Collaborative Notepad: Real-time shared notepad with bidirectional sync, Phone Pair QR code, and multi-device editing.
  • Configurable Expiration & Custom Slugs: Set links to expire in 1 hour, 6 hours, 1 day, 7 days, 30 days, or permanently, with custom vanity slugs and edit codes.

Frequently Asked Questions

Can I share large files (multiple gigabytes, videos, ISOs) on Clip?

Yes. One Clip link holds any number of files, up to 500 MB in total, and they are deleted 2 hours after upload. For anything bigger, Clip Beam (https://clip.foo.ng/beam) sends files directly from your browser to the recipient over an encrypted peer-to-peer WebRTC connection, so nothing is uploaded and no account is needed. Chrome and Edge stream straight to disk, so multi-gigabyte files work; Firefox and Safari handle files up to about 2 GB. Both people need to keep their tabs open until it finishes.

How does Clip compare to WeTransfer, Mega, and Google Drive?

Unlike Google Drive, Mega, or WeTransfer, Clip requires no account, no email address, and no software installation. Clip Beam sends large files directly between two browsers, so there is no cloud upload to wait for. The trade-off is that both people must be online at the same time, while cloud services keep the file for later.

How does free file sharing and text sharing work on Clip?

Simply paste your text or drop your files into Clip. You can optionally set a custom URL slug, secret edit code, expiration timer, or zero-knowledge encryption password. Click 'Create Link' to instantly receive a shareable link with no account required.

Is Clip safe, anonymous, and encrypted?

Yes. Clip requires no login, email, or personal details. If you choose password protection, text and file payloads are encrypted directly in your browser using AES-GCM 256-bit encryption before upload. The server never receives your password or decryption keys. Without a password, shares are stored as-is, so use one for anything private.

What is the Live Pad real-time sync feature?

Live Pad allows multiple devices to type and drop files into the same room URL in real time without manually saving each change. It includes a Phone Pair QR code to instantly sync between desktop and mobile devices.

How long do shared files and texts remain online?

Text entries can be set to expire in 1 hour, 6 hours, 1 day, 7 days, 30 days, or permanently. Uploaded files are deleted 2 hours after upload. Clip Beam peer-to-peer transfers are never stored: the file goes straight from one browser to the other.
